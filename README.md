# Карточка товара Teaboom

Тестовое задание: адаптивная вёрстка карточки товара интернет-магазина чая **Teaboom.ru**.

Проект представляет собой страницу товара «Ананасовый улун» с интерактивным выбором фасовки, обновлением цены, кнопками добавления в корзину, избранным и модальным окном для увеличения изображения.

## Демо

Для запуска откройте файл `index.html` в браузере или используйте расширение **Live Server** в VS Code.

## Возможности

- Адаптивная вёрстка карточки товара.
- Семантическая HTML-разметка.
- Методология БЭМ для именования CSS-классов.
- Хлебные крошки и заголовок товара.
- Основное изображение и миниатюра товара.
- Кнопка увеличения изображения.
- Модальное окно с увеличенной картинкой.
- Закрытие модального окна:
  - кнопкой `×`;
  - кликом по затемнённому фону;
  - клавишей `Escape`.
- Выбор фасовки товара:
  - 100 г;
  - 500 г;
  - 1000 г;
  - 5000 г.
- Автоматическое обновление текущей и старой цены при выборе фасовки.
- Визуальное выделение активной фасовки.
- Добавление товара в корзину через кнопку в строке фасовки.
- Общая кнопка «В корзину».
- Добавление и удаление товара из избранного.
- Поддержка клавиатурной навигации:
  - `Enter` или `Space` для выбора фасовки;
  - `Escape` для закрытия модального окна.
- Состояния `hover`, `focus-visible` и `active` для интерактивных элементов.
- Базовые ARIA-атрибуты для улучшения доступности.

## Запуск проекта

### Вариант 1. Открыть HTML-файл

1. Скачайте или склонируйте проект.
2. Перейдите в папку проекта.
3. Откройте файл `index.html` в браузере.

### Вариант 2. Live Server в VS Code

1. Откройте папку проекта в Visual Studio Code.
2. Установите расширение **Live Server**, если оно ещё не установлено.
3. Нажмите правой кнопкой мыши по `index.html`.
4. Выберите пункт **Open with Live Server**.

После этого страница будет открыта на локальном сервере. При сохранении файлов браузер сможет автоматически обновлять страницу.

## Интерактивность

### Выбор фасовки

При нажатии на строку фасовки:

1. Строка получает активный фон.
2. У предыдущей фасовки удаляется активное состояние.
3. Меняется итоговая цена.
4. Меняется старая цена.
5. Можно выбрать фасовку клавишами `Enter` или `Space`.

Данные по фасовкам хранятся в объекте `productVariations` в файле `js/main.js`.

```js
const productVariations = {
  100: {
    currentPrice: "326,40 ₽",
    oldPrice: "349,20 ₽",
  },
  500: {
    currentPrice: "1 432 ₽",
    oldPrice: "1 646 ₽",
  },
  1000: {
    currentPrice: "2 064 ₽",
    oldPrice: "2 592 ₽",
  },
  5000: {
    currentPrice: "6 320 ₽",
    oldPrice: "8 710 ₽",
  },
};
```

### Избранное

Кнопка с сердцем переключает состояние товара:

- `♡` — товар не добавлен в избранное;
- `♥` — товар добавлен в избранное.

Также обновляются:

- CSS-класс активного состояния;
- значение `aria-pressed`;
- текст `aria-label`.

### Модальное окно

Модальное окно открывается:

- нажатием на изображение товара;
- нажатием на кнопку с иконкой лупы.

Модальное окно закрывается:

- по клику на кнопку закрытия;
- по клику на overlay;
- по клавише `Escape`.

При открытии блокируется прокрутка страницы через класс:

```css
body.modal-open {
  overflow: hidden;
}
```

## Адаптивность

Вёрстка выполнена по принципу desktop-first с адаптацией под разные размеры экрана.

### Desktop

На ширине от `768px`:

- изображение находится в левой колонке;
- фасовки и цена находятся в правой колонке;
- используется CSS Grid.

### Планшеты и мобильные устройства

На ширине менее `768px`:

- карточка перестраивается в одну колонку;
- фото располагается над фасовками;
- таблица фасовок сохраняет читаемость;
- итоговая цена и кнопка покупки подстраиваются под ширину экрана.

## Доступность

В проекте предусмотрены базовые улучшения доступности:

- У изображений есть `alt`.
- Кнопки имеют `type="button"`.
- У интерактивных элементов есть `aria-label`.
- У кнопки избранного используется `aria-pressed`.
- У модального окна используются `role="dialog"` и `aria-modal="true"`.
- Для фасовок используются `tabindex` и `aria-selected`.
- Для интерактивных элементов предусмотрены `:focus-visible` состояния.
- Модальное окно закрывается с клавиатуры клавишей `Escape`.
